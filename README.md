# 口琴小曲库 · 曲谱来源索引

这里维护 58 首固定来源索引（48 首社区新增、10 首原有 TXT）和 3 首可再分发的原创测试谱。桌面程序首次下载歌曲后保存在本机，可以离线使用。

本仓库不包含第三方歌曲谱面。`sources.json` 只包含标题、作者、版本、原地址和完整性摘要；社区文件从作者原地址下载并在本机转换，不经过本仓库转存。任何来源文件的版权仍属于原权利人，公开可下载不等于允许复制发布。

`original/` 为本项目原创测试谱，可按 MIT 许可分享。仓库的 MIT 许可只适用于本项目自己的文件，不授予外部链接所指曲谱的任何额外权利。

社区曲目已核对转换前后音高、时值、休止和顺序。逐首对照原曲录音听校未完成；不表示游戏内兼容性或账号安全经过验证。

导入个人谱面请使用 UTF-8 TXT（HarmonicaPlayer/1）；视频、MP3、图片不是可直接演奏的谱面。软件中的“下载曲谱”可处理索引里已验证的社区来源格式。

## 更新规则

来源必须使用不可变提交地址、字节数和 SHA-256；新版谱面分配新版本，不覆盖个人改编。新增第三方谱面镜像必须先具备明确再分发依据。发布时逐文件检查，不打包个人曲谱、下载缓存、凭据或日志。
