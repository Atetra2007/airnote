# 三角洲口琴 · 朋友使用包

先使用原版 **HarmonicaPlayer v0.2.1**，用这个小包管理下载、曲谱来源和验证记录。适用 Windows 10/11 x64、国服 PC；无需 Python、.NET SDK、账号系统或服务器。

**v0.1.1-logtest 已在 Windows 11 上运行原版，仅日志模式完成《父亲》《晴天》《雨爱》三首样本。** 开始、F8 长音中停止、停止按钮、中文路径另存与重新导入、未保存时取消新建/关闭、播放中退出和重启默认日志模式已验证。10 首候选的音乐节奏仍待人工校对；倒计时取消、断网和朋友首次使用等仍待验收，详见[验证记录](docs/VALIDATION.md)。

## 给朋友的 3 步

1. 从[新版下载页](https://github.com/Atetra2007/delta-force-harmonica-kit/releases/tag/v0.1.1-logtest)下载 `harmonica-friends-kit-v0.1.1-logtest.zip`，解压到自己好找的文件夹。双击 `index.html` 打开中文曲库索引。
2. 双击 `Prepare.cmd`。它从作者的固定版本下载原版 ZIP 和 10 首候选谱，核对散列后解压，**不会启动播放器**。初次需要联网；已有文件会复核，不会覆盖改过的谱。
3. 先正常退出游戏，再打开 `local/player/v0.2.1/HarmonicaPlayer.exe`。确认界面中的 **“仅日志测试”已勾选**，导入 `scores/original/01-timing-check.txt`。点击开始或按 F6，按 F8 或停止按钮结束。日志模式没有声音，这是正常现象；然后再导入下方三首样本。

**脚本被系统阻止时：**保持系统策略和安全提示原样，使用[作者原版下载页](https://github.com/lanselanlanxi-wq/HarmonicaPlayer/releases/tag/v0.2.1)手动下载解压，再在 `index.html` 中打开单首“原始 TXT”，另存为同名 UTF-8 TXT。浏览器可能直接显示文本；这时用“网页另存为”，并确认扩展名是 `.txt`，不是 `.html`。不要把 GitHub 网页保存成曲谱。

本包不包含上游 EXE 和这 10 首谱面，因此压缩包很小；初次仍需下载约 65.6 MB 的原版 ZIP。下载不通会显示具体失败项，已正确下载的文件可重复使用。私有仓库下载需要获授权的 GitHub 账号；朋友没有账号时，可以直接分享本仓库的使用包 ZIP，让他们从原作者获取播放器和曲谱。

## 选曲与导入

- `index.html`：离线搜索、筛选首轮样本或“日志通过”、收藏、勾选后导出来源清单。它是曲库索引页，不会播放或发送键鼠输入；浏览器视觉和点击验收仍待完成。
- `local/scores/`：准备脚本下载的 10 首个人用候选谱。首轮按《父亲》72 BPM →《晴天》67 BPM →《雨爱》新版 80 BPM 检查。
- `scores/original/`：本项目原创的短测试谱，可随包分享。
- 你自己的 TXT：直接用播放器“导入”；整理与分享规则见[添加曲谱](docs/ADDING_SCORES.md)。MIDI、MusicXML、图片、视频和 MP3 不能直接交给这个版本。

“文件完整”“能导入”“日志运行完成”“节奏正确”“游戏内验证”分别记录。当前导入和整段日志通过 **3 首**，已校对推荐曲目为 **0 首**。没有节奏的纯数字谱不能自动变成准确的歌曲。

本机约 2 秒观察到首次启动窗口（含工具开销）；多首日志测试后静置 30 秒，工作集约 249 MiB、私有内存约 227 MiB。原版长界面需要滚动查看底部日志，且日志超过 150 行后会清空，因此不适合作为完整演奏记录。这些是单次本机观察，不是性能保证。

## 使用边界

游戏自动输入仍存在违规和封禁风险。[腾讯公告](https://df.qq.com/cp/a20240906main/newsdetail.html?id=3109167722633874126)列有自动脚本、鼠标宏及相关硬件，未找到口琴豁免说明。日志测试不证明游戏兼容或账号安全。本包不提供输入规避、驱动或硬件替代方案；游戏内自动演奏不在这一轮验收范围内。

原版 EXE 未带 Authenticode 签名；已校验的散列只能确认与固定 GitHub 发行附件一致，不等于软件安全审计。若 Windows 或安全软件出现提示，保留提示，不关闭防护或自行放行。
