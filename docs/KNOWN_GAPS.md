# 当前体验缺口

| 项目 | 目前情况 | 下一步 |
| --- | --- | --- |
| 已验证播放器 | 本轮没有启动原版 | 游戏关闭后做日志模式验收 |
| 精选程度 | 10 首候选，0 首节奏校对完成 | 先查父亲、晴天、雨爱，不靠数量冒充精选 |
| 音乐正确性 | 文件完整性与元数据已核对 | 另做谱面节奏校对；不能从散列推断音准 |
| 本地试听 | 原版 v0.2.1 不提供 | 需要试听时使用独立音乐工具，不改原版 |
| MIDI / 播放列表 | 原版 v0.2.1 不支持 | 先用 TXT；需求稳定再比较许可明确的播放器 |
| 曲库 UI | 本包有离线来源索引、收藏与勾选清单 | 曲谱仍由原版播放器的导入按钮打开 |
| 速度、片段循环 | 现有速度设置以原版为准；本包不增加片段循环 | 实测需求后再判断是否值得开发 |
| 轻量与稳定 | 只有文件大小证据 | 记录启动时间、内存、中文路径、缩放、保存与关闭 |
| 朋友安装体验 | 没有真实朋友试用 | 先测 1 人，再扩大到 5–10 人 |
| 再分发 | 原版无明确许可证，候选谱许可未确认 | 继续引用原作者下载，不复制发布 |

如果后续决定开发自己的播放器，应先解决授权或使用许可证明确的项目。输入后端换语言、驱动、硬件或 AI，不能据此宣称免封。
