# 当前体验缺口

| 项目 | 目前情况 | 下一步 |
| --- | --- | --- |
| 原版验证 | 3 首导入及完整日志通过；启停、中文保存、播放中关闭和重启已测 | 补倒计时取消、未保存后导入、断网与不同缩放 |
| 精选程度 | 10 首候选，3 首日志通过，0 首音乐节奏校对完成 | 逐小节对照父亲、晴天、雨爱；未校对不进入推荐 |
| 日志留存 | 原版超过 150 行会清空，长曲结束后只有后段 | 记录完成状态；不要把界面日志当完整轨迹 |
| 本地试听 | 原版 v0.2.1 不提供 | 音乐校对需借助原谱及独立音乐工具 |
| MIDI / 播放列表 | 原版 v0.2.1 不支持 | 暂用 TXT；需求稳定后比较许可明确的播放器 |
| 曲库 UI | 搜索、收藏、日志状态筛选和来源清单导出已实现；尚未通过浏览器点击验收 | 朋友按实际浏览器试用；曲谱仍用原版导入 |
| 界面布局 | 原版默认长界面需要滚动查看日志 | 先收集朋友设备实际问题，不擅改全局缩放 |
| 速度、片段循环 | 速度使用原版 BPM；本包未增加片段循环 | 依据真实使用频率决定后续开发 |
| 内存与稳定性 | 运行多曲后空闲工作集约 249 MiB，私有内存约 227 MiB；仅本机单次快照 | 不宣传极轻量；补朋友设备、长时运行观察 |
| 朋友安装体验 | 没有真实朋友完整试用 | 先测 1 人，再扩大到 5–10 人 |
| 再分发 | 原版无明确许可证，候选谱许可未确认 | 保留原作者下载和来源链接，不复制发布 |

当前适合继续使用原版的小范围日志试用，尚不足以证明需要从零开发播放器。优先补节奏校对和一位朋友的真实体验；如果确实需要试听、MIDI 或播放列表，再以许可明确的项目为基础评估。

日志通过不等于游戏兼容。更换语言、驱动、硬件或 AI 输入不能据此宣称免封。
