# 当前桌面版与曲库的已知限制

当前主线是独立编写的 HarmonicaDesk 桌面程序；v0.4.1-preview.1 通过 [GitHub Release 预发布页](https://github.com/Atetra2007/delta-force-harmonica-kit/releases/tag/v0.4.1-preview.1)提供。仓库为私有，下载需要仓库访问权限。Release 附件及安装升级状态见[本轮状态记录](RELEASE-0.4.1-STATUS.md)，旧版原始播放器的测试记录保留在[历史原版验证记录](VALIDATION.md)，不能用来证明新桌面程序通过。

| 项目 | 目前边界 | 后续处理 |
| --- | --- | --- |
| 复核覆盖 | 当前目录有 34 份已复核片段，覆盖 32 个作品；221 个作品组没有已复核片段，另有 7 个版本暂缓 | 按[校准队列](CALIBRATION-QUEUE.md)选择具体版本和片段，保留证据与文件哈希 |
| 未知 BPM | 453 个版本中有 273 个 BPM 未知：266 个没有 `bpm` 字段，7 个值为 `null` | 有来源证据时再校准；没有证据时保持未知，不填默认速度 |
| 作品归并 | 253 个作品组的身份判断仍可能暂定；相同标题、别名或来源不能单独证明是同一首曲子 | 有旋律身份依据时再更新归并，保留来源版本 |
| 谱面与原曲一致性 | 校验哈希只能说明文件未变；来源时值核对、导入成功和本地合成试听都不能证明谱面完整准确 | 已复核范围只覆盖对应片段和版本；不要向其他版本继承标签 |
| 全曲听校 | 当前没有完成全部作品的人工听音或全曲节奏验收；片段复核不等于整曲校准 | 需要逐段记录原曲版本、时间范围、复核结果和问题点 |
| 游戏与账号安全 | 桌面自动输入的局部功能检查不证明所有歌曲、所有按键组合或所有机器都兼容，也不证明符合游戏规则或免封 | 真实游戏验证单独记录；不提供反检测或规避方案 |
| 外部格式 | 应用以兼容 TXT 为主要曲谱输入；MIDI、MusicXML、图片、视频和 MP3 不能直接保证转换准确 | 转成 TXT 后逐段确认音高、时值、休止和 BPM |
| 干净机器与朋友试用 | 本机自动化检查不能代替干净 Windows 安装和朋友首次使用 | 按[桌面版验证记录](DESKTOP-VALIDATION.md)继续完成实际安装和使用观察 |

当前目录的统计与来源哈希见[曲库状态](CATALOG-STATUS.md)。v0.4.0 已发行范围及历史验证见[0.4.0 状态记录](RELEASE-0.4.0-STATUS.md)；本轮候选检查见[0.4.1 状态记录](RELEASE-0.4.1-STATUS.md)。原版 HarmonicaPlayer v0.2.1 的三首样本日志检查仅属于历史旧程序记录，详见[历史原版验证记录](VALIDATION.md)。

本地试听不会发送键鼠输入；游戏演奏会模拟普通键鼠输入，存在违反游戏规则和封禁的风险。局部功能通过或版本独立实现都不能据此宣称安全。
