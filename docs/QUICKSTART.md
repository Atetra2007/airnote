# Airnote：快速上手

Airnote 是“口琴小曲库”（HarmonicaDesk）的新项目名称。本说明对应目前已发布的 v0.4.3；该版本安装包和桌面入口仍使用旧名称。

适用 v0.4.3，Windows 10 22H2 / Windows 11 x64。安装包自带运行时和全部 374 份已复核 TXT，覆盖 244 首作品，另有 3 份原创测试谱。使用本软件不需要 Python、.NET SDK 或软件账号。

## 安装并试听第一首

1. 打开 [v0.4.3 发布页](https://github.com/Atetra2007/airnote/releases/tag/v0.4.3)，在 Assets 下载 `HarmonicaDesk-Setup-0.4.3-win-x64.exe` 和同名 `.sha256`。Release 下载无需 GitHub 登录；GitHub 的 Source code ZIP 不是安装包。
2. 核对摘要后运行安装包，从桌面“口琴小曲库”打开应用。安装后曲库直接可用，无需逐首下载或另找 TXT，断网也能选曲。
3. 在“本地”中搜索并选择一首歌曲，保持右侧“本地试听”，点击底部“试听”。正常音频输出设备下会听到合成音；点击“停止”结束。需要完整谱面时点击顶部“曲谱”。

默认 F6 开始、F8 停止。快捷键被其他软件占用时，界面会显示原因；本地试听仍可用窗口按钮操作。软件每次启动进入本地试听，不会自动播放。

## 曲库与曲谱

夜间石墨界面把选曲和看谱分开。打开应用先看到曲库，右侧仅放当前曲目、版本、模式和速度；点击顶部“曲谱”或“查看曲谱”进入完整谱面，长谱可翻页。底部播放控制一直可见。

右侧直接选择本地试听、跟谱手弹或自动演奏。0.5×、0.75×、1×、1.25×、1.5× 是临时速度倍率，不改写原谱 BPM，也不会产生未保存修改。跟谱模式另外提供浮窗、定位与 A/B 循环。

在“曲谱”页签点击“编辑”可修改曲名和正文，并显示保存／另存副本。直接修改原谱 BPM 属于曲谱修改，保存后才保留。谱面显示真实音高和每个音的时值，竖线只来自原谱中的 `|`。

- **搜索**：按 Ctrl+F 或 Ctrl+K 定位搜索框，可输入歌名、别名、拼音、来源作者、参考演奏者、版本或 BPM。空格可组合条件，例如 `晴天 137`、`曲名 副歌`；每个条件必须命中同一版本。忽略大小写、全半角和常见标点。
- **排序**：智能排序先看搜索相关度，再优先本地、收藏和最近使用；也可切换曲名 A–Z 或最近使用。别名、作者和版本命中会说明匹配原因。
- **视图**：全部、本地、收藏、最近一键切换；状态筛选可叠加“已复核片段”或“速度待确认”。“最近”按开始试听或练习的时间排列；打开一首曲目不会增加记录。
- **版本**：同一作品只占一行，`2/6 版` 表示 6 个版本中有 2 个满足当前条件。在右侧选择版本；筛选临时选出的版本不会覆盖原有版本偏好。没有手动选择记录时，优先打开本地已复核片段或本地版本。
- **键盘**：搜索框内按 Enter 选择首个结果，按 ↓ 进入列表并用上下键选曲；列表内 Esc 返回搜索框，搜索框内 Esc 清空搜索。这些选曲操作不会自动开始播放。
- **筛选**：列表显示作品和版本数量，“重置筛选”清空搜索与筛选；收藏和版本选择继续保留。

## 加入歌曲

| 手里有什么 | 怎么添加 |
| --- | --- |
| 随包提供的歌曲 | 在“本地”中选曲，直接试听或查看曲谱 |
| “全部”中尚未导入的其他来源版本 | 选择版本，按主按钮提示下载或导入；“前往来源”可核对作者页面 |
| 一个或多个兼容 TXT | 点击“＋ 导入 TXT”多选文件，或直接拖入窗口 |
| 一整个曲谱文件夹 | 点击导入按钮旁的“⋯ → 导入文件夹 / 旧使用包” |
| 以前下载的朋友使用包 | 在同一入口选择旧包根目录，程序复制 `local/scores` 和 `local/my-scores` 的 TXT，原文件保留 |
| Codex 整理的文本 | “⋯ → 粘贴曲谱”，或“新建曲谱”后粘贴正文、设置 BPM 并保存 |

随包曲库包含 374 份已复核 TXT、244 个作品，另有 3 份原创示例。总表的 780 个版本记录还包括参考版本，并不全部内置。部分曲谱只覆盖指定片段；同名其他版本不会自动继承复核状态。选择“本地”可集中查看已经可用的曲谱。

支持下载的其他来源版本会从固定来源获取并核对大小与 SHA-256；需要格式转换的版本还会校验转换结果。下载失败不会影响已安装曲库和个人曲谱。私人导入不会自动加入 GitHub 或后续安装包。

同样的内容重复导入会选用已有条目；同名但内容不同的曲谱会独立保留。单首 TXT 最大 1 MiB，一次最多导入 500 首。TXT 需要使用 UTF-8 编码并符合支持的简谱格式，MIDI、图片、视频链接和 MP3 不能直接导入。

## 检查与修改曲谱

在曲库右侧调整临时速度即可用于试听或练习；需要永久改变 BPM 时，在“曲谱”页签调整原谱速度并保存。没有注明速度的旧谱会要求确认 BPM；不确定时先核对来源，避免把默认速度当成歌曲正确速度。

点击“编辑”修改谱面，再点击“预览”查看音高和拍数。错误提示旁可点击“定位”。修改后点击“保存”或按 Ctrl+S；希望保留当前版本时点击“另存副本”。切歌或关闭前若有未保存修改，选择“取消”可以继续编辑。

本地试听用 C 调合成音检查旋律与节奏，可调音量，不模拟游戏口琴原声。“已复核片段”只对相应文件和记录范围有效，不表示全部歌曲完成真人听辨或游戏实测。“下载校验通过”“能够解析”“播放完成”也不等于歌曲节奏已经正确。

## 主题、快捷键与游戏模式

新增“跟谱手弹”：选择“节奏跟弹”或“等键练习”，在游戏口琴界面按 F6 开始。F6 暂停／继续，F7 隐藏／显示浮窗，F8 停止。浮窗显示八条键位轨道，音符头到线按下、尾端到线松开。主窗口可设置练习倍率、A/B 循环、不透明度和浮窗位置。详细规则见[跟谱手弹说明](GUIDE.md)。跟谱不会模拟按键，等键模式只在游戏前台时监听八个音键与三个鼠标修饰键；退出、停止或切出会停用判定。

右上“设置”可选择跟随系统／浅色／深色，调整开始和停止热键以及当前曲谱音符间隔。开始与停止需使用不同的 F1–F12 键，可组合 Ctrl、Alt、Shift；发生占用时换用可注册的组合。间隔变化属于曲谱修改，需保存后保留。

游戏演奏衔接过紧时，可调整“设置 → 游戏换音留白”，默认 60 毫秒，可调至 0–250。快音会限制附加留白，原谱 BPM 和休止不变；0 表示仅用曲谱自带间隔。该设置对所有游戏自动演奏生效，不改写曲谱，不影响本地试听或跟谱。若开始前提示某个音过短，请核对提示的音符或降低 BPM；不要把这个提示当作文件损坏。详情见[节奏修复记录](RHYTHM-VALIDATION.md)。

**游戏自动输入可能违反游戏规则并导致封禁，普通键鼠输入也不能保证账号安全。** 本机已完成同权限下三个长音的用户听辨验证，详见[游戏验证记录](GAME-VALIDATION.md)；这不代表全部歌曲、组合键或朋友首次使用已验收。不接受账号风险时，请使用本地试听和看谱，并自行在游戏中按键。

游戏中取出口琴后，先按 R 切到显示 `Z X C V B N M ,` 的**手动演奏**界面；亲手按 Z 确认发声。再在口琴小曲库选择“自动演奏”，切回游戏按 F6，演奏期间保持游戏在前台。程序的“跟谱手弹”只提示谱面，需要自己按音键。

如果手按有声、程序显示播放完成却无声，请检查两者的运行权限。本机出现过“游戏为管理员、播放器为普通权限”的不一致；经用户同意，将原版播放器仅本次以管理员身份启动后，三个长音恢复发声。需要这种对照时，先正常退出播放器，再右键桌面快捷方式 →“以管理员身份运行”，由本人确认 Windows 提示。这是一次性启动方式；其他无声情况仍需按具体原因排查。

游戏模式有 3 秒可取消倒计时；开始后需切回游戏口琴窗口并松开启动热键。倒计时结束时前台不是三角洲客户端、热键不可用、窗口切换或发生手动按键冲突时，程序会拒绝或停止输入。涉及鼠标修饰键的音符还要求鼠标留在目标窗口内。随时按停止热键结束；若提示释放失败，点击停止重试，并按照提示检查相应按键。

该保护用于减少误输入，不证明游戏支持输入，更不是反检测功能。本项目没有驱动、硬件替代或免封承诺。

## 备份、升级与卸载

个人数据目录是 `%LOCALAPPDATA%\HarmonicaDesk`。在资源管理器地址栏粘贴该地址，备份整个文件夹即可保存曲谱、收藏、最近使用和设置。其中 `Scores` 是个人曲谱，`desktop.log` 为本地诊断日志。

程序安装目录是 `%LOCALAPPDATA%\Programs\HarmonicaDesk`。升级前正常关闭应用，再运行新安装包；新版随包曲库自动可用，并保留个人谱面、收藏、最近使用与版本偏好。不需要单独导入歌曲压缩包。卸载默认保留个人数据；需要完全删除自己的数据时，应另行确认并手动处理，安装器不会替你删除曲谱。

## 遇到问题

- **没声音：**确认选择“本地试听”、音量不为零，并检查 Windows 当前音频输出；查看“来源与诊断”中的具体错误。
- **曲谱报错：**使用“定位”，核对括号、升号、附点、减时线、休止和 BPM。不要让整理工具随意补全缺失节奏。
- **下载失败：**查看错误与“查看来源”；可稍后重试，或把自己已获取的兼容 TXT 导入。
- **Windows 提示来源或签名：**此版本尚未签名；先核对 Release 来源、文件名及摘要，不关闭系统防护。摘要只能证明下载完整性。
- **需要反馈：**记下版本、具体步骤和错误文字。诊断日志可能含个人文件路径，分享前先检查并去掉不必要的信息。

新版验证结果见[桌面版验证记录](DESKTOP-VALIDATION.md)。旧版原播放器的[历史测试记录](VALIDATION.md)只适用于当时的 HarmonicaPlayer v0.2.1，不能替代新版测试。
