# 口琴小曲库：给朋友的快速说明

适用 v0.3.0-preview.1，Windows 10 22H2 / Windows 11 x64。使用本软件不需要 Python、.NET SDK 或软件账号。

## 安装并试听第一首

1. 本次提供本地预览 `HarmonicaDesk-0.3.0-preview.1-win-x64.zip` 与同名 SHA-256 文件，尚未发布到 GitHub Release。
2. 将 ZIP 完整解压到一个文件夹，双击其中 `App/HarmonicaDesk.exe`。本地试听无需管理员权限或额外运行时；不要只复制 EXE。
3. 选择左侧原创测试谱，确认底部选择“本地试听”，点击“开始”。看到音符高亮，正常音频输出设备下会听到合成音；点击“停止”结束。

默认 F6 开始、F8 停止。快捷键被其他软件占用时，界面会显示原因；本地试听仍可用窗口按钮操作。软件每次启动进入本地试听，不会自动播放。

## 加入歌曲

| 手里有什么 | 怎么添加 |
| --- | --- |
| 软件左侧列出的歌曲 | 选择曲目，再点击中间“下载曲谱”；也可“查看来源”核对作者页面 |
| 一个或多个兼容 TXT | 点击“＋ 导入 TXT”多选文件，或直接拖入窗口 |
| 一整个曲谱文件夹 | 点击导入按钮旁的“⋯ → 导入文件夹 / 旧使用包” |
| 以前下载的朋友使用包 | 在同一入口选择旧包根目录，程序复制 `local/scores` 和 `local/my-scores` 的 TXT，原文件保留 |
| Codex 整理的文本 | “⋯ → 粘贴曲谱”，或“新建曲谱”后粘贴正文、设置 BPM 并保存 |

软件共有 58 首来源曲目和 3 首原创示例。可搜索“欧布小曲”等别名，列表显示版本与时长。歌曲不会随安装包分发。点击下载时，软件从作者的固定来源获取，核对大小与 SHA-256 后才保存；社区来源会在本机自动转换成兼容 TXT，并再次校验转换结果，不需要自己转谱。网络失败或内容不符会显示原因；已在个人曲库中的文件与内置测试谱不需要重新下载。

同样的内容重复导入会选用已有条目；同名但内容不同的曲谱会独立保留。单首 TXT 最大 1 MiB，一次最多导入 500 首。TXT 需要使用 UTF-8 编码并符合支持的简谱格式，MIDI、图片、视频链接和 MP3 不能直接导入。

## 检查与修改曲谱

选择曲目后，在右下调整“速度 BPM”。没有注明速度的旧谱会要求确认 BPM；不确定时先核对来源，避免把默认速度当成歌曲正确速度。

点击“编辑”修改谱面，再点击“预览”查看音高和拍数。错误提示旁可点击“定位”。修改后点击“保存”或按 Ctrl+S；希望保留当前版本时点击“另存副本”。切歌或关闭前若有未保存修改，选择“取消”可以继续编辑。

本地试听用 C 调合成音检查旋律与节奏，可调音量，不模拟游戏口琴原声。新增 48 首已核对转换保留来源音高与时值，原有 10 首已重做解析检查；逐首原曲听校仍未完成。“下载校验通过”“能够解析”“播放完成”都不等于歌曲节奏已经正确。

## 主题、快捷键与游戏模式

新增“跟谱手弹”：选择“节奏跟弹”或“等键练习”，在游戏口琴界面按 F6 开始。F6 暂停／继续，F7 隐藏／显示浮窗，F8 停止。浮窗显示八条键位轨道，音符头到线按下、尾端到线松开。主窗口可设置练习倍率、A/B 循环、不透明度和浮窗位置。详细规则见[跟谱手弹说明](GUIDE.md)。跟谱不会模拟按键，等键模式只在游戏前台时监听八个音键与三个鼠标修饰键；退出、停止或切出会停用判定。

左下“设置”可选择跟随系统／浅色／深色，调整开始和停止热键以及当前曲谱音符间隔。开始与停止需使用不同的 F1–F12 键，可组合 Ctrl、Alt、Shift；发生占用时换用可注册的组合。间隔变化属于曲谱修改，需保存后保留。

**游戏自动输入可能违反游戏规则并导致封禁，普通键鼠输入也不能保证账号安全。** 本机已完成同权限下三个长音的用户听辨验证，详见[游戏验证记录](GAME-VALIDATION.md)；这不代表全部歌曲、组合键或朋友首次使用已验收。不接受账号风险时，请使用本地试听和看谱，并自行在游戏中按键。

游戏中取出口琴后，先按 R 切到显示 `Z X C V B N M ,` 的**手动演奏**界面；亲手按 Z 确认发声。再在口琴小曲库选择“自动演奏”，切回游戏按 F6，演奏期间保持游戏在前台。程序的“跟谱手弹”只提示谱面，需要自己按音键。

如果手按有声、程序显示播放完成却无声，请检查两者的运行权限。本机出现过“游戏为管理员、播放器为普通权限”的不一致；经用户同意，将原版播放器仅本次以管理员身份启动后，三个长音恢复发声。需要这种对照时，先正常退出播放器，再右键桌面快捷方式 →“以管理员身份运行”，由本人确认 Windows 提示。这是一次性启动方式；其他无声情况仍需按具体原因排查。

游戏模式有 3 秒可取消倒计时；开始后需切回游戏口琴窗口并松开启动热键。倒计时结束时前台不是三角洲客户端、热键不可用、窗口切换或发生手动按键冲突时，程序会拒绝或停止输入。涉及鼠标修饰键的音符还要求鼠标留在目标窗口内。随时按停止热键结束；若提示释放失败，点击停止重试，并按照提示检查相应按键。

该保护用于减少误输入，不证明游戏支持输入，更不是反检测功能。本项目没有驱动、硬件替代或免封承诺。

## 备份、升级与卸载

个人数据目录是 `%LOCALAPPDATA%\HarmonicaDesk`。在资源管理器地址栏粘贴该地址，备份整个文件夹即可保存曲谱、收藏、最近使用和设置。其中 `Scores` 是个人曲谱，`desktop.log` 为本地诊断日志。

程序安装目录是 `%LOCALAPPDATA%\Programs\HarmonicaDesk`。升级前正常关闭应用，再运行新安装包。卸载默认保留个人数据；需要完全删除自己的数据时，应另行确认并手动处理，安装器不会替你删除曲谱。

## 遇到问题

- **没声音：**确认选择“本地试听”、音量不为零，并检查 Windows 当前音频输出；查看“来源与诊断”中的具体错误。
- **曲谱报错：**使用“定位”，核对括号、升号、附点、减时线、休止和 BPM。不要让整理工具随意补全缺失节奏。
- **下载失败：**查看错误与“查看来源”；可稍后重试，或把自己已获取的兼容 TXT 导入。
- **Windows 提示来源或签名：**此预发布尚未签名；先核对 Release 来源、文件名及摘要，不关闭系统防护。摘要只能证明下载完整性。
- **需要反馈：**记下版本、具体步骤和错误文字。诊断日志可能含个人文件路径，分享前先检查并去掉不必要的信息。

新版验证结果见[桌面版验证记录](DESKTOP-VALIDATION.md)。旧版原播放器的[历史测试记录](VALIDATION.md)只适用于当时的 HarmonicaPlayer v0.2.1，不能替代新版测试。
