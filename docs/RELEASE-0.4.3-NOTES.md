# v0.4.3 · 安装自带曲库

新版安装后直接拥有全部已复核曲库，不再需要逐首寻找 TXT。随包提供 **374 份 TXT，覆盖 244 首作品**，原始总量 737,201 字节，约 0.74 MB；另附 3 份原创测试谱。首次启动离线可用。

## 下载与使用

打开 [v0.4.3 发布页](https://github.com/Atetra2007/delta-force-harmonica-kit/releases/tag/v0.4.3)，在 Assets 下载 `HarmonicaDesk-Setup-0.4.3-win-x64.exe` 和同名 `.sha256`。核对摘要后安装，从桌面“口琴小曲库”打开，在“本地”中选曲试听即可。不需要单独曲库 ZIP；GitHub 自动生成的 Source code ZIP 不是安装包。

仓库目前为私有，下载需要仓库访问权限。已经下载的安装包和内置曲库可离线使用，不需要软件账号。已有用户升级前正常退出应用；升级保留个人曲谱、收藏、最近使用和版本偏好。详细操作见[快速说明](QUICKSTART.md)。

## 界面与操作

- 夜间石墨配色，以曲库作为主页面；完整谱面改为顶部“曲谱”页签，长谱分页查看。
- 右侧集中当前版本、本地试听、跟谱手弹和自动演奏设置，底部保留播放控制。
- 三种模式均可使用 0.5×—1.5× 临时倍率，不改写原谱 BPM。
- 搜索、收藏、最近使用和质量筛选继续可用；其他未内置来源版本按原有入口下载或导入。

## 曲库范围

374 份由此前 34 份和本轮新增 340 份组成，均按对应文件哈希绑定复核记录。当前目录共 244 个作品、780 个版本记录，后者包含未内置的来源参考版本；不能将其写成“780 份已复核 TXT”。部分谱面只覆盖指定片段，已复核状态不自动延伸到整首作品或其他版本。详情见[当前曲库状态](CATALOG-STATUS.md)。

安装包不包含录音、来源图片、研究原材料和用户个人谱面。外部曲谱的 `redistribution=permission-unconfirmed` 状态保持不变；本次随包提供不代表获得原作者授权，也不将谱面纳入本项目 MIT 许可。详见[来源与许可](../THIRD_PARTY.md)。
