## 三首样本

| 曲目 | BPM / 间隔 | 音/休止事件数 | 拍数 | 预览预计时长 | 实际观察 |
| --- | --- | --- | --- | --- | --- |
| 父亲 | 72 / 20ms | 124 | 68.5 | 57.083 秒 | 导入检查通过；完整日志运行结束 |
| 晴天 | 67 / 20ms | 247 | 132 | 118.209 秒 | 导入检查通过；完整日志运行结束 |
| 雨爱（新版） | 80 / 20ms | 195 | 124 | 93 秒 | 导入检查通过；完整日志运行结束 |

以上时长来自原版预览，不含 3 秒倒计时，**不是实测音频时长**。三首均实际看到“日志测试完成：未发送键鼠，不会发声”。《父亲》《晴天》的旧格式 BPM 从文件名读取，《雨爱》新版从文件头读取。

原版日志行数超过 150 时会清空后继续追加（固定版本 `Program.cs` 第 528 行）。因此《晴天》《雨爱》结束时只保留后段日志；不能宣称保留了完整事件审计，更不能以此证明音乐正确或真实输入时序准确。

## 启动与内存

- 首次从启动请求到工具发现主窗口约 **2044ms**。包含工具开销，不等同于严格冷启动或可交互时间基准。
- 完成多首日志与保存测试后，主界面静置 30 秒，在无播放、无对话框时采样：工作集 **260,771,840 字节（248.69 MiB）**，Private Bytes **238,116,864 字节（227.09 MiB）**。
- 内存为单次、本机、运行过曲谱之后的空闲快照；二者含义不同，不相加，也不从 ZIP 体积推算。尚无长期稳定性结论。

## 朋友使用包验证

准备脚本、发布边界的 8 项自动化测试覆盖缓存复核、中文路径、损坏文件拒绝覆盖、ZIP 路径检查、缺失文件和打包白名单。它们验证使用包，不替代原版 GUI 测试。

曲库页进行了 JavaScript 语法、离线数据同步和文件链接检查。内置浏览器 URL 策略阻止本地 file URL，因此未完成浏览器视觉与点击验收，未绕过该限制。

原始 GUI 文本记录、内存快照和关闭检查留在个人 `local/offline-validation/`。文件对话框包含本机路径，记录也可能含谱面，不直接上传。公开 JSON 仅保留脱敏统计和结论。
