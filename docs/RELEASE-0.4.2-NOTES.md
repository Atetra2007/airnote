# v0.4.2 · 校对阶段收尾

本版将已完成的曲谱校对成果和搜索界面改进汇入发行版本，并按用户决定移除剩余 13 个未解决的来源版本。同曲的其他已通过版本保留，个人曲库不作删除处理。

## 本阶段结果

- 原范围：221 个作品、352 个来源版本。
- 通过：339 个来源，形成 340 份修订编配。
- 移除：13 个未解决来源，涉及 12 个作品；移除不等于音乐校对通过。
- 现行总表：244 个作品、780 个版本；374 份具有指定范围的复核记录，包含此前 34 份与本阶段新增 340 份。

[阶段处置清单](../catalog/calibration-stage-20261014.json)列出移除的来源标识。[当前曲库状态](CATALOG-STATUS.md)保留来源参考版本的实际分类；片段可以仅覆盖原来源已有的乐句范围，复核不自动延伸为整首歌曲通过。

## 软件变化

改进搜索、作品列表与版本选择，整合作品名、别名、拼音和版本信息检索。复核信息支持录音与出版乐谱两类依据，并绑定对应曲谱的 SHA-256；错误文件、修改后的内容或同名其他版本不能继承已复核标识。批量审计工具验证生产解析、隔离导入、重启与错误哈希拒绝。

更新后，已移出目录且未导入的旧预览占位不再出现在选曲列表；已经保存的个人曲谱、收藏、最近使用和版本偏好保留。缺文件的私人导入记录也不会被当作目录占位清理。

## 下载与使用

仓库为私有，下载需要仓库访问权限。打开 [v0.4.2 发布页](https://github.com/Atetra2007/airnote/releases/tag/v0.4.2)，在 Assets 中选择：

- `HarmonicaDesk-Setup-0.4.2-win-x64.exe`：当前用户安装包。
- `HarmonicaDesk-0.4.2-win-x64.zip`：完整解压后运行 `App/HarmonicaDesk.exe`，无需另装 .NET。
- 对应 `.sha256` 与 `publish-manifest.json`：核对下载文件与程序内容。

已有应用请先正常退出。安装器按设计保留 `%LOCALAPPDATA%\HarmonicaDesk` 中的个人曲谱和设置；便携 ZIP 不自动更新快捷方式。GitHub 自动生成的 Source code ZIP 不是可运行安装包。

本包包含程序、曲库元数据和 3 份原创测试谱。第三方完整曲谱、录音及本机研究材料不随包发布；使用本阶段编配仍需在自己的电脑导入对应曲谱。

## 验证范围

软件测试、生产解析和包内哈希校验不代替真人听辨或实机游戏验收；本次没有进行真实游戏、干净 Windows 安装或覆盖升级界面验收。原始证据和之前的未完成检查点保留，本阶段按用户批准的移除范围结束。详见[验证记录](RELEASE-0.4.2-STATUS.md)。
