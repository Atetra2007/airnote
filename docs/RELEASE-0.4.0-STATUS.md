校正版依据原版录音的混音谱图、分离人声、两种独立音高估计以及发音/波形逐音复核，明确处理漏音、重复音、换气、起音与释放。每份校正版通过生产 C# 解析器与核准时间线的逐事件比较。此证据不包含人工听音或实际游戏测试，逐音边界也存在单音乐器改编的取舍。

## 已通过的软件验证

- Core 104 个测试、Windows 41 个模拟场景、Desktop 26 个存储场景通过；Windows 场景不产生真实游戏键鼠或音频输出。
- Python 包装/准备测试 20 项通过；桌面发布检查自检通过。仓库和桌面打包入口均校验校准证据的实际文件、SHA、来源身份与参考录音绑定，并拒绝缺失、篡改、错配、链接或孤立文件。
- 当前 schema 3 索引在生产 LibraryStore 中加载 368 版本、250 作品，30 份校正版全部成功导入；哈希、事件数、时长、重启后的收藏、每个作品所选版本均通过。测试使用隔离数据目录，网络请求为 0。
- 自包含 Windows x64 候选编译通过。实际窗口读取到 253 个作品（含3个原创示例）、31个本地作品，以及《晴天》《雨爱》各4个版本。
- 本地候选 ZIP 的 410 个应用文件均通过允许清单、大小、SHA-256 与压缩包 CRC 检查；随包提供合并歌单和当前缺口说明。

实际 GUI 操作未通过：两次隔离启动均可读取窗口和截图，但控制工具返回 `failed to activate captured window`，无法完成搜索、版本切换、试听进度与停止的交互验收。隔离测试进程已关闭；此前安装的预览版与个人数据未改动。

## 未满足的正式发行条件

- 11 条社交来源仍未保存：4 个 B 站视频谱、5 篇专栏，以及抖音《爱错》《红尘客栈》的两个特定来源。专栏按用户指示保留待核验线索。另一作者或平台的同名谱不冒充这些来源的保存结果。
- 4 个 B 站视频的原生截图此前被自动安全审查拒绝，原因是无法可靠确定浏览器当前 URL；没有更换工具绕过该拒绝，也没有将缺失帧计作保存。
- 只有 28 / 250 个作品拥有已复核片段；其余作品仍有原曲身份、源谱对应、逐音时值、音高或分段问题。拥有音频或算法定位不等于校准通过。
- 《薪火永燃》052、蒲公英169、反乌托邦069等独立提案仍有明确争议，未加入批准目录。《薪火永燃》还修正了一处过早起音，但漏音/并音与滑音目标音高仍未解决。
- GUI 交互、最终安装升级、正式发行附件及最终原曲质量验收仍需完成。提交 CI 结果以 GitHub Actions 对应提交的检查为准；CI 通过不代表音乐和界面验收完成。

开发分支可用于审阅当前实现和来源盘点。以上条件全部满足后，才能发布正式 v0.4.0 并执行用户要求的“完成后延迟60秒关机”。当前没有安排关机。
