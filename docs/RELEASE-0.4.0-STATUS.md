本文记录 v0.4.0 的曲库范围与源数据验证。当前目录 `catalog/songs.json` 的 SHA-256 为 `476c6f3c54ce095bbc10c025b5651bbef692a7a2dec70623ca7d1e2f2f35edc3`；该哈希与 `local/catalog-0.4.0/fast-scope-finalization-016.json` 及 `final-local-audit-016.json` 中记录的目录哈希一致。CI 构建、安装升级和发行资产的最终验收见 [GitHub Release](https://github.com/Atetra2007/airnote/releases/tag/v0.4.0)。当前目录统计见[曲库状态](CATALOG-STATUS.md)，v0.4.1 本轮构建与运行验证见[0.4.1 状态记录](RELEASE-0.4.1-STATUS.md)。

| 已复核片段 | 34 份片段，覆盖 32 个作品。完成逐音视觉音频复核并与生产解析结果比对；不代表全曲完成，也不代表人工听音或游戏实测通过。 |

第三方完整曲谱、校正版和音频只保存在本机。GitHub 和安装包只包含程序、来源元数据及验证摘要；不随包分发第三方曲谱或音频。具体曲目与来源见[合并歌单](RELEASE-0.4.0-SONG-LIST.md)。

## 已有软件验证

- Core 104 项、Windows 41 项输入模拟、Desktop 27 项存储检查、Python 20 项准备与打包测试已通过。模拟检查不会产生真实游戏输入。
- 生产曲库存储加载 453 个版本和 253 个作品；隔离验证导入 100 份缓存直下载谱、28 份 MIDI 转换、17 份仓库转换、4 份速度调整版和 34 份复核片段后重启，文件哈希、收藏、选定版本和复核状态通过；实际网络请求为 0。
- 当前目录有 273 个版本的 BPM 未知（266 个字段缺失、7 个显式 `null`）；未以默认速度填充。旧的隔离运行报告 `local/catalog-0.4.0/runtime-audit-011/report.json` 记录 262 个未知 BPM，但其目录哈希为 `5814d66871f37a7e2315e67cd9565602731dda0961ae1cc76a99c805d6d34307`，与当前目录哈希不同。因此 262 是另一份目录快照的运行结果，不能当作当前 453 版本目录的导入验证结论。只有报告中 `catalog_sha256` 与本页目录哈希相同，才可视为验证了这份目录快照。
- 个人曲库导入先在副本预演，再写入实际资料目录；183 个版本完成导入。本机可用 186 个版本、131 个作品（含 3 个原创示例），原有 34 个谱文件哈希不变，收藏、最近使用与设置保留，9 个旧文件恢复索引关联。
- 隔离候选 GUI 已验证搜索《晴天》、切换复核版本、本地试听进度与停止；《His Theme》也完成开始、进度和停止检查。用户安装版最终结果见 Release，不将界面操作当作实际听音或游戏测试。

## 尚有限制

全曲、全库校准不是 v0.4.0 的发行门槛。本次按分级范围发布：34 份片段只覆盖 32 个作品，且不是整首；另外 221 个作品组没有已复核片段。参考谱可能需要用户检查、编辑或导入，未知 BPM 不会被当作已确认速度。**本曲库不保证全部 253 个作品都可播放。**

难曲和存在发音、滑音、错位等争议的草稿继续暂缓；来源保存和导入成功也不能证明谱面与原曲一致。没有声称完成每首原曲的人工听音、整曲节奏验收或游戏实测。
