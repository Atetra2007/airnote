## 节奏与可用性

31 份校正版有逐音波形、混音谱图、分离人声和两种音高估计复核，并与生产 C# 解析结果逐事件比对；这是片段的视觉音频核验，不是整首听音验收。4 份速度调整版保留源音高、休止和相对时值，只调整原版整体速度，明确显示“逐音待校”。

微信编辑器的受控导出已确认：四分设置省略时值字段，八分对应数组末项或对象 `d=8`，`b=1` 对应“按着”的横杠，`|` 由“空格”按钮产生。`16`、横杠及空格的精确播放时值仍未确认；217 份 JSON 全部原样保留，尚未给未证实的字段补时值。钢琴复音、重叠或超出口琴音域的来源只作为参考谱；不会通过静默删音生成声称准确的口琴谱。

## 已通过的软件验证

- Core 104 项、Windows 41 项输入模拟、Desktop 26 项存储检查，以及 Python 20 项准备/打包测试通过。模拟检查不产生真实游戏输入。
- 生产 LibraryStore 加载 450 版本、254 作品，导入 100 份缓存直下载谱、28 份 MIDI 转换、17 份仓库转换、4 份速度调整和 31 份校正版后重启，文件哈希、收藏、选定版本和校准状态通过；实际网络请求为 0。
- 隔离数据中 262 个版本仍保持未知 BPM，没有被默认速度冒充确认结果。
- 实际 GUI 已验证搜索《晴天》、切换校正版、试听进度和停止；扩充后的《His Theme》也完成开始/进度/停止。版本选择框显示类型名的问题已修复。此前“窗口无法激活”的失败已由这些成功交互结果取代。

GUI 证据来自隔离候选，用户安装的预览版和个人数据尚未升级。原安装版占用 F8，候选正确禁用了游戏演奏；本次 GUI 只验证本地试听，不代表实际听校或游戏测试。最新构建附件与 CI 以对应提交结果为准。

## 尚未完成

- 225 个作品组尚无逐音复核片段；已有 29 组也不等于全曲完成。原版录音身份记录中有 142 项已支持、104 项未决；其余没有对应中央记录。
- 《不谓侠》《薪火永燃》《反乌托邦》等草案仍有发音、滑音或错位争议，未加入批准目录。《蒲公英的约定》已完成该来源片段的复核，明确保留声乐滑音的离散口琴改编限制。
- 全量作品身份、每首原曲节奏验收、正式安装升级与 v0.4.0 正式发行尚未完成。

用户要求的“全部完成后延迟 60 秒关机”尚未触发，目前没有安排关机。
