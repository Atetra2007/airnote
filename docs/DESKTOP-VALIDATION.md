# v0.2 桌面版验证记录

本记录仅适用于独立的口琴小曲库 v0.2.0-preview.1。2026-09-24 在 Windows 开发机使用 x64 .NET SDK 10.0.300 验证；原版 HarmonicaPlayer 的历史测试见 [VALIDATION.md](VALIDATION.md)，两者不能互相替代。

## 已完成

- Core 解析测试 89 项，Windows 播放与停止模拟测试 18 项，桌面存储测试 13 项，全部通过。
- 发布目录包含自带运行环境；明确清单验证 410 个文件，排除个人曲谱、上游程序及输入接收测试工具。
- 独立接收窗口实测普通 SendInput：键盘 6 次按下、6 次释放，鼠标 4 次按下、4 次释放，数量匹配。未启动游戏。
- 实际桌面窗口完成内置示例本地试听，显示播放完成；检查深色、浅色及启动时跟随系统主题。合成音输出成功不等于人工听辨音准或完成音乐节奏校对。
- 实际 UI 验证：曲库搜索、来源下载与散列校验、F6 开始与长音中 F8 停止、关闭前未保存提示与取消、另存副本且原谱未改变。两次启动只保留一个进程。游戏模式在倒计时后发现前台不是游戏而拒绝输入。
- 存储测试覆盖中文路径、原文件保留、重复与同名导入、旧包目录、保存失败后重试、坏索引恢复及并发设置保存。
- 修复保存／切歌异步竞态、索引损坏覆盖示例、深色背景及停止重试问题。

- 真实 WPF 根布局离屏检查 4/4 通过：880×600 与 1080×720，分别浅色／深色；开始、停止、BPM、音量、谱面均界内且互不重叠。最小尺寸按 96-DPI 标准边框估算，谱面仍有约 504×196 DIP。这是组件布局检查，不等于实机缩放或不同 DPI 验收。

## 安装与性能实测

使用 GitHub Actions 成功产出的 `fc69147` 安装包，在当前 Windows 非管理员令牌下安装。安装器不要求提权；程序落在当前用户 Programs 目录，桌面与开始菜单快捷方式均指向安装的 EXE。对安装后的 410 个文件逐一比较 CI 文件清单中的 SHA-256，全部匹配。

| 项目 | 实际结果 |
|---|---|
| 安装包 | 46,443,270 字节，约 44.3 MiB；最终附件的准确大小与 SHA-256 以 Release 为准 |
| 安装内容 | 410 个文件，约 139.5 MiB；含运行时与许可说明 |
| 首次桌面快捷方式启动至 READY 日志 | 1,051 ms（外部计时，包含进程启动与日志检测） |
| 程序内部启动至首次呈现 | 606 ms |
| 启动后空闲 30 秒工作集 | 143,007,744 字节，约 136.4 MiB |
| 同期私有内存 | 104,787,968 字节，约 99.9 MiB |
| 同版本覆盖安装 | 通过；6 个个人文件 SHA-256 均不变，包括曲谱、收藏、设置和日志 |
| 卸载 | 程序与两处快捷方式移除；上述 6 个个人文件完整保留 |
| 卸载后重新安装 | 410 个安装文件及两处快捷方式再次验证通过 |

性能是本机首启的一次样本，内存采样前未接入 UI 自动化。编辑、加载长谱与 UI 自动化后内存可以上升；此前临时测试进程曾观察到约 190 MiB 工作集，不将 180 MiB 作为上限保证。同版覆盖验证不能替代未来跨版本数据迁移测试。

安装版窗口确认默认本地试听、不自动播放；内置示例完成播放，音量从 20% 调到 21% 并持久化，收藏也已落盘。输入接收器只用于开发验证，不在安装包内。

## 尚未验证

- 干净 Windows 环境、朋友首次下载使用、真实游戏输入和账号安全。
- 不同 DPI、系统主题实时切换、全流程断网环境与人工听辨音准／节奏。
- 原生文件选择器的完整批量导入操作与拖放交互：本轮 UI 自动化无法可靠定位该原生对话框的控件，因此未标为端到端通过；实际导入与中文路径、去重、原文件保留已经由存储层测试覆盖。没有修改系统网络设置来模拟断网。
- 倒计时取消、前台变化及异常清理有模拟测试；独立接收窗口证明正常输入与释放数量，不能替代每一故障路径的真实 Windows 输入实测。

新程序记录与旧版日志验证完全分开。最终发布标签、CI 与附件摘要在 Release 中一起列出。
