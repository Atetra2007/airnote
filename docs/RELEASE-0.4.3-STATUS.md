# v0.4.3 发行与验证记录

2026-10-14，用户选择将全部已复核 TXT 随软件提供，以安装 EXE 为主要下载方式。本记录区分实现目标、实际检查和尚未完成的验收；在结果填入前，不把目标视为已经通过。

## 本版范围

- 374 份已复核 TXT，覆盖 244 个作品，原始总量 737,201 字节；另保留 3 份原创测试谱。
- 仓库资源位于 `scores/bundled/`，安装包资源位于 `Resources/BundledScores/`；首次启动离线可用。
- 保留 780 个目录版本的真实状态，未把所有来源版本作为内置 TXT；复核记录仍绑定具体哈希与片段范围。
- 沿用夜间石墨、曲库主页面和独立曲谱页签，保留临时速度及原有演奏保护。
- 升级保留个人曲谱、收藏、最近使用与版本偏好；用户私人内容不进入随包曲库。

## 保持未完成的验收

本次后台执行，不操作用户键鼠、不抢占其他应用焦点、不自动播放声音或发送游戏输入。隐藏窗口或隔离数据检查不等同于真实游戏操作。

干净 Windows 安装、朋友首次使用、真人全曲听辨、全部游戏组合键和跨屏体验仍需分别记录实际结果。已有历史验证范围见[桌面版验证记录](DESKTOP-VALIDATION.md)、[跟谱验证记录](GUIDE-VALIDATION.md)及[游戏验证记录](GAME-VALIDATION.md)。
