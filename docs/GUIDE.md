# 跟谱手弹 · v0.3.0-preview.1

选择底部“跟谱手弹”，程序用独立半透明浮窗提示音符，由你在游戏中实际按键。首次启动仍默认本地试听，不会自动开始跟谱或监听。窗口化／无边框模式为支持目标，独占全屏不保证覆盖；本机浮窗走谱、切出暂停与手动恢复已有用户实测确认，其他逐项结果见[游戏验证记录](GAME-VALIDATION.md)。

## 开始练习

1. 选曲并确认原曲 BPM。在主窗口选择“节奏跟弹”或“等键练习”，按需要选择练习倍率。
2. 打开游戏口琴界面。按开始热键，或在主窗口点开始后于倒计时内切回游戏。首次有 3 秒预备，期间松开音键。
3. 浮窗八轨对应 `Z X C V B N M ,`；音符头到薄荷色横线时按下，长条尾端到线时松开。浮窗约显示接下来 3 秒的内容。

| 方式 | 推进规则 |
| --- | --- |
| 节奏跟弹 | 按 BPM × 倍率连续推进，不判断对错 |
| 等键练习 | 音符到线后全谱冻结，新的正确音键按下才继续；休止按时值经过 |

等键模式只检查起音组合，不评分长音松键时机。鼠标修饰键可以一直按住；同一个音连续出现时，必须松开音键再按下。键盘长按的重复消息、开始／恢复时已经按住的音键都不能通过下一音。错按会短暂显示所需组合，不跳音。监听初始化失败会显示原因，此时可以暂停后选择“节奏跟弹”。

## 看懂音符

- 中音为薄荷绿，低音为蓝色，高音为琥珀色；`↓`、`↑`、`↑↑`、`#` 同时标出音区和升音，不必只靠颜色辨认。
- 长条上的鼠标小图标标出修饰按钮；浮窗下方完整写出“左键＋中键＋C”等当前组合，并预告下一音。
- 指法严格来自程序现有 `GameKeyMapping`：低音加左键，高音按标准映射使用右键，高音 1 使用逗号；升音加中键。以浮窗完整文字为准，不推断等价指法。
- “休止”时松开音键。程序停止和暂停不会替你松开实体按键。

## 快捷键、暂停与隐藏

| 默认键 | 作用 |
| --- | --- |
| F6 | 开始／暂停／继续 |
| F7 | 隐藏／显示浮窗；隐藏会暂停，显示后等待继续 |
| F8 | 停止并回到 A 起点，未选片段则回到全曲开头 |

已有的开始和停止快捷键继续有效，浮窗会显示实际配置。设置中可以更改浮窗热键；新增热键冲突时会明确提示，保留原开始／停止设置，仍可用主窗口“浮窗”按钮。

暂停冻结时间与谱面。恢复和每次片段循环有 2 拍预备，预备拍跟随练习速度。切出游戏自动暂停并隐藏；切回后保持暂停，按开始键继续。主窗口可以最小化；退出应用会关闭浮窗、计时器及监听。

## 放慢、定位和反复练习

暂停后可选择 `0.5× / 0.75× / 1× / 1.25× / 1.5×`。倍率始终相对于原谱 BPM，不写回原谱；自动演奏用的音符间隔也不会缩短跟谱长条。

点击主窗口谱面中的某个音符，或输入音符编号（休止也占一个编号），然后点“定位”“设 A”或“设 B”。范围从 A 的起点到 B 的结束，包含 B 的完整时值；A=B 即为单音练习。勾选“循环”可重复，点“全曲”清除片段。换曲会清空 A/B；主窗长谱只显示前 1000 音，之后可直接输入编号。定位、倍率和模式调整均需暂停后进行。

## 调整浮窗

默认大小 560×280 DIP，最小 440×240。背景默认 75% 不透明，可在主窗口调至 35%—95%；文字与音符不随背景透明度变淡。

先暂停，再点“调整浮窗”：拖标题移动，用右下角缩放。调整时浮窗可在任务栏切换；再次开始时自动锁定、从任务栏隐藏、鼠标穿透且不抢焦点。位置、尺寸、背景不透明度、模式和倍率保存到现有个人设置；位置失效时会尝试移回可见显示器区域。显示器热插拔和跨 DPI 移动仍需实机验收。

## 数据与验证

预览版继续使用 `%LOCALAPPDATA%\HarmonicaDesk` 的个人曲谱与设置，旧设置缺失新增字段时使用默认值。正常关闭旧应用，再解压运行新预览包；不要覆盖或清理个人数据目录。

已完成的自动、组件和桌面窗口验证，以及尚未完成的物理输入／游戏验证，见[本版验证记录](GUIDE-VALIDATION.md)。开发用输入接收器不在发行包中。
