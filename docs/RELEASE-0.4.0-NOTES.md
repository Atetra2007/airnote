# v0.4.0 发布说明：分级曲库

本页说明 v0.4.0 的分级曲库范围。安装包、CI 构建与安装升级验收结果见 [GitHub Release](https://github.com/Atetra2007/airnote/releases/tag/v0.4.0)。

## 解决的问题

曲库扩充后，同一作品可能有多个来源谱、改编和校正版。只看曲目标题，容易把“已找到来源”误认为“已经校准”，也不容易看出哪些内容经过了复核。v0.4.0 按作品归组、保留各来源版本，并明确显示复核状态。

## 曲库如何分级

当前索引归为 **253 个作品组、453 个版本**，比原索引新增 195 个作品组。415 条来源记录中有 404 条已保存。

| 标记 | 含义 |
| --- | --- |
| 已复核片段 | 34 份片段覆盖 32 个作品。逐音视觉音频复核只适用于对应片段，不表示整首歌曲已核准。 |
| 参考谱·未校准 | 412 个版本，含 4 份整体速度调整版；供查看、编辑或导入，逐音准确度与实际可演奏性尚未确认。目录中 266 个版本的 BPM 未知，隔离导入后 262 个仍保持未知。 |
| 暂缓校对 | 7 个版本，分布于反乌托邦混编、反乌托邦、不谓侠、真的爱你 4 个作品组；继续暂缓，不作为已确认校正版宣传。 |

所有 253 个作品组都至少有一份已保存来源。微信原始谱 220 / 220 已保存，100 条来源可直接下载并核对大小与 SHA-256。11 条最初指定的 B 站／抖音原帖仍未取得，但已有替代来源覆盖相应作品。来源与版本清单见[合并歌单](RELEASE-0.4.0-SONG-LIST.md)。

## 已验证范围

- Core 104 项、Windows 41 项输入模拟、Desktop 27 项存储检查、Python 20 项准备与打包测试已通过。
- 隔离验证中，生产曲库加载 453 个版本、253 个作品；183 个版本、128 个作品完成导入与重启检查。文件哈希、收藏、选定版本和复核状态通过，实际网络请求为 0。
- 个人曲库导入经副本预演后执行：183 个来源与复核版本导入，本机可用 186 个版本、131 个作品（含 3 个原创示例）；原有 34 个谱文件哈希不变，收藏、最近使用和设置保留，恢复了 9 个已存在文件的索引关联。
- 隔离候选界面完成搜索《晴天》、切换复核版本、本地试听进度与停止检查；《His Theme》也完成开始、进度和停止检查。用户安装版的最终验收记录在 Release 中。

## 使用限制

全曲全量精校不属于本次发行门槛。34 份复核材料都是片段，覆盖 32 个作品；另外 221 个作品组没有已复核片段。来源已保存或成功导入，不等于谱面与原曲一致。曲库不承诺全部 253 个作品都可播放，也没有声称完成人工整曲听音或游戏实测。第三方完整曲谱、校正版和音频只保存在本机，GitHub 和安装包仅包含程序、来源元数据及验证摘要。
